# Built to Move 깊이 읽기

## 책의 한 문장 요약

몸의 자유는 거창한 운동보다 매일의 기본 움직임에서 시작된다.

## RAYUL BOOKS 리뷰

Built to Move는 운동 프로그램이라기보다 몸 사용 설명서에 가깝습니다. 관절, 호흡, 자세, 균형, 걷기처럼 너무 기본적이라 놓치기 쉬운 영역을 다시 보게 합니다.

40대 이후에는 강한 운동보다 꾸준히 움직일 수 있는 몸이 먼저입니다. 오래 앉아 일하는 사람이라면 이 책이 꽤 직접적인 점검표가 됩니다.

## 읽을 때 볼 지점

- 관절과 자세의 기본 상태
- 하루 중 앉아 있는 시간
- 운동 전후가 아니라 일상 전체의 움직임

## 주의할 점

통증이 있거나 질환이 있다면 무리해서 따라 하기보다 전문가 조언을 함께 받는 것이 좋습니다.
